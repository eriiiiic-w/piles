系统架构设计

前后端分离，单进程运行。FastAPI 同时提供 API 和托管前端静态文件。

│  │  │ Design  │ │ R3F+Drei │ │ AG Grid      │  │  │
│  │  └─────────┘ └──────────┘ └──────────────┘  │  │
│  └───────────────────────────────────────────────┘  │

技术栈明细
前端
React 18 · TypeScript · Vite
Ant Design 5 · Zustand (状态管理)
React-Three-Fiber · Drei
AG Grid (数据表格)

后端
FastAPI · Uvicorn
SQLAlchemy · SQLite
Pandas · NumPy · PyKrige
Openpyxl (Excel 读写)
目录结构
桩基智能体/
├── server/ FastAPI 后端
│ ├── api/ 路由层
│ ├── models/ SQLAlchemy 模型
│ ├── services/ 业务逻辑层
│ ├── core/ 复用现有计算引擎
│ └── main.py
├── client/ React 前端
│ ├── src/
│ │ ├── components/
│ │ ├── pages/
│ │ ├── store/ Zustand
│ │ └── three/ R3F 3D
│ └── vite.config.ts
