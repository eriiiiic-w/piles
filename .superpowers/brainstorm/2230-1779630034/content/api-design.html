REST API 设计

FastAPI 路由规划。保留现有 core/ 模块的计算能力，上层换为 REST 接口。

API 端点一览
模块方法路径说明
项目GET/api/project获取当前项目信息、数据摘要
地勘POST/api/geo/upload上传地勘 Excel，返回数据概览
地勘GET/api/geo/layers获取土层列表（用于下拉菜单）
地勘GET/api/geo/holes勘探孔列表（支持分页/搜索）
桩基POST/api/piles/upload上传桩基 Excel
桩基GET/api/piles桩列表（分页/筛选/搜索）
桩基GET/api/piles/{id}单桩详情（含预测结果）
预测POST/api/predict/single/{id}单桩预测（克里金/IDW）
预测POST/api/predict/all批量预测全部桩
预测GET/api/predict/scene-data3D 场景数据（IDW 快速模式）
实测POST/api/measured录入某桩某层实测标高
实测GET/api/measured/{pile_id}查询某桩实测记录
设置PUT/api/settings更新持力层、阈值、插值方法等
设置GET/api/settings获取当前设置
承载力POST/api/bearing/calc/{pile_id}单桩承载力计算
承载力POST/api/bearing/params上传土层参数(qsik/qpk)
导出GET/api/export/predictions导出全部预测 Excel
导出GET/api/export/measured-holes导出实测勘探孔
导出GET/api/export/record/{pile_id}导出打桩记录文本

设计原则

  • 现有 core/ 模块零修改或极小修改
  • API 层只做薄封装：校验输入 → 调 core → 返回 JSON
  • 文件上传用 multipart/form-data
  • 大数据导出用 StreamingResponse

与旧架构对照

  • DataStore.load_geo_data() → POST /api/geo/upload
  • PredictEngine.predict_one() → POST /api/predict/single/{id}
  • BearingCalc.calculate() → POST /api/bearing/calc/{id}
  • DataStore.save/load() → SQLite 自动持久化
