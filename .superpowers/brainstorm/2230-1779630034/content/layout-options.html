选择整体布局方案

报告建议采用 Abaqus / Flac3D 风格的专业工程软件布局。以下是三种主流工程软件的布局模式：

A

Abaqus 风格 — 经典工程布局

左项目树 + 中央工作区(Tabs) + 底部消息面板

左侧常驻项目导航树（模型/数据/结果），中央多标签工作区（数据管理、预测、3D），底部输出控制台/日志栏。右侧无固定面板，通过弹窗/抽屉查看详情。

优点：工作区大，适合数据处理。缺点：属性面板非固定，需额外点击。

B

Flac3D 风格 — 三栏专业布局

左项目树 + 中央工作区 + 右侧属性面板 + 底部控制台

四区块固定：左侧导航、中央主视图（占最大面积）、右侧属性检查器（点击对象后联动显示详情）、底部消息/命令控制台。所有面板可拖拽、折叠。

优点：信息密度高，专业感强。符合报告全部建议。缺点：实现复杂度较高。

C

VS Code 风格 — 灵活面板布局

左侧活动栏 + 侧边栏 + 中央编辑区 + 底部面板

左侧图标活动栏切换不同侧边栏（文件/数据/搜索），中央为大工作区，底部可展开面板（终端/输出/日志）。面板可拖拽到右侧。

优点：灵活、熟悉。缺点：工程软件"感"较弱，偏开发工具风格。
